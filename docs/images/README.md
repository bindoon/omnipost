# README 配图

当前工作台与侧栏截图使用项目构建出的界面、仓库内示例配图和模拟任务状态。README 通过相对路径引用图片。

| 文件                    | 来源与用途                                                               |
| ----------------------- | ------------------------------------------------------------------------ |
| `video-workbench.png`   | 当前版本视频工作台，展示同一视频的任务归组、草稿、预约已填写和预约已提交 |
| `article-workbench.jpg` | 当前版本文章工作台，展示公众号正文复制、各平台草稿进度和右侧排版预览     |
| `schedule-panel.png`    | 当前版本视频号侧栏，展示「填入素材和定时」及横竖封面                     |
| `channels-fill.png`     | 原文章中的视频号实拍，记录视频上传和文案填写过程                         |
| `connect-ai.png`        | 原文章中的桥接配对截图，令牌输入框为空                                   |

原文章为 `myskills` 仓库的《多平台视频和文章的一键发布插件，已开源》。本目录也保留该文章的封面、流程图和排版对比图。

平台能力和验收范围见 [平台能力](../capabilities.md)。
